# Direction créative

Le grain, le fermoir puis l'objet dans la pièce : un sac vert profond est traité comme une icône de design, sans fausse marque ni porteur ajouté.

Palette : #174f50, #b89850, #e7e5db.

Lumière : Fenêtre diffuse, reflet doré doux sur fermoir, lumière stable sur cuir grainé.

Caméra : trois échelles optiques, déplacements très courts ; pas de mouvement spectaculaire nécessaire. Étalonnage simple sans modifier le produit. Texte composé après rendu avec une police système librement utilisable par le système de production.

Continuité : Grain, surpiqûres, rabat, fermoir doré, poignée, absence de marque ; pas de changement de couleur ni de quincaillerie.

Montage : trois séquences de 5 s pour les films produit ; 2,5 s de signature. Le film performance recoupe ces séquences en gardant une lecture produit et une durée totale identique. Aucun arrêt sur image ne remplace une génération échouée.

Son : Résonance métal douce, frottement de matière, souffle de raccord ; aucun faux bruit d'ouverture. Piste exécutée : Reverie, Scott Buckley, CC BY 4.0, crédit à conserver. Référence musicale créative : reverie, pas une promesse de piste téléchargée.
